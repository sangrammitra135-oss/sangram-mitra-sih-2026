> **"Skills Today. Employment Tomorrow."**  
> A unified, outcome-driven platform that diagnoses real-time skill gaps, verifies training milestones, authenticates employment offers with dual-handshakes, tracks 3/6/12-month retention and wage progression, and provides macro district-level skilling intelligence.

---

## 🌟 Key Highlights & Capabilities

1. **🧠 Adaptive Skill Assessment Engine:**
   - Real-time diagnostic evaluation across Technical (Python, SQL, DSA, Cloud) and Behavioral STAR employability dimensions.
   - Instant rubric feedback and dynamic score recalibration.

2. **📊 AI Skill-Gap Radar & Career Matching:**
   - Side-by-side gap delta analysis against live market hiring benchmarks.
   - Exportable **Verified Digital Skill Passport** with cryptographic hash.

3. **📚 Verifiable Training & Course Roadmap:**
   - Curated programs from accredited partners (*APSSDC, Skill India Digital, NASSCOM FutureSkills Prime, AWS Academy*).
   - Milestone tracking with verifiable certificate badges.

4. **💼 Dual-Handshake Employer Verification:**
   - Direct HR-authenticated placement verification queue preventing ghost placements.
   - Automatic recording on a tamper-evident outcome ledger.

5. **📈 3 / 6 / 12-Month Retention & Wage Progression:**
   - Longitudinal tracking of candidate livelihood sustainability.
   - Tracking wage trajectories (*₹28,500/mo &rarr; ₹32,000/mo &rarr; ₹38,000/mo*).

6. **🔎 "Why Not Placed?" Root-Cause Diagnostic Matrix:**
   - Pinpoints barriers across Technical deficits, Interview readiness, Mobility constraints, and Resume ATS compatibility.
   - Automatically prescribes targeted intervention sprints.

7. **🗺️ District-Level Skill Demand & Heatmap Analytics:**
   - Interactive district intelligence for policy planners and collectors.
   - Sector-wise demand breakdowns, placement conversion charts, and 1-click CSV data export.

8. **🌓 Universal Light & Dark Mode:**
   - Ambient, high-contrast theme system with smooth transitions and persistent state.

## 🚀 Getting Started

### Local Setup
No build tools or heavy dependencies required. Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js / npx
npx serve .
```

Open `http://localhost:8080` in your browser.
